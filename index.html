02 / HOW I WORK

A practical QA mindset.

Automation is one part of quality. The value comes from choosing the right checks and making the results useful.

01 / TEST WITH INTENT

Understand before validating.

Start from requirements and user behaviour. Explore negative paths, edge cases, state changes, and risks—not just the happy path.

02 / AUTOMATE DELIBERATELY

Build checks you can trust.

Use maintainable structure, reusable components, and clear assertions so failures are easier to reproduce and investigate.

03 / MAKE FEEDBACK USEFUL

Communicate with evidence.

Report clear reproduction steps, expected and actual outcomes, and impact—so teams can make informed decisions.
